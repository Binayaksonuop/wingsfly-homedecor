# Wingsfly HomeDecor | Premium Interior Studio

A state-of-the-art modern web experience for an interior design and architecture studio. Built with a focus on editorial typography, smooth inertial scrolling, and responsive masonry layouts.

## Live Preview
*(You can add your Vercel/Netlify link here once deployed)*

## ✨ Features
- **Premium Aesthetics:** High-end, magazine-style editorial design.
- **Buttery Smooth Scrolling:** Powered by `Lenis` for a native app-like scroll experience.
- **Complex GSAP Animations:** ScrollTriggers, staggered reveals, and sophisticated micro-interactions.
- **Dynamic Masonry Grid:** Custom SCSS grids for projects and feature collections.
- **Fully Responsive:** Perfectly scales from 375px mobile screens up to 1920px+ ultra-wide displays.
- **Dynamic Routing:** React Router v7 configured for instant project detail page transitions.

## 🛠️ Tech Stack
- **Frontend:** React.js, TypeScript, Vite
- **Styling:** Vanilla SCSS (Custom Design System, BEM Methodology)
- **Animations:** GSAP & ScrollTrigger
- **Smooth Scroll:** Lenis 
- **Icons:** Lucide React
- **Carousels:** Swiper.js

## 🚀 Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) with your browser to see the result.

## 📦 Production Build

To build the app for production, run:

```bash
npm run build
```

This will generate optimized static assets in the `dist/` folder, which can be deployed to Vercel, Netlify, or any static host.
